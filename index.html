Tentang Sistem

Sistem ini menggunakan Finite State Automata (FSA) untuk memvalidasi format ID pesanan secara otomatis. Setiap ID pesanan harus mengikuti format: ORD-XXXX-YYYY

FSA bekerja di background untuk memvalidasi setiap ID yang di-generate atau di-input oleh user. Jika format tidak sesuai, sistem akan menolak dan memberikan pesan error yang jelas.

Format ID Valid

Format: ORD-XXXX-YYYY

• ORD = Prefix (3 huruf kapital)

• XXXX = 4 digit tahun (0-9)

• YYYY = 4 digit nomor urut (0-9)

Contoh: ORD-2024-0001, ORD-2025-9999
