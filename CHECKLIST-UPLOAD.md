# ✅ Checklist Upload ke GitHub Pages

## 📋 Sebelum Upload

- [x] File `index.html` sudah ada di root folder
- [x] File `styles.css` sudah ada di root folder
- [x] Path di `index.html` sudah benar:
  - [x] CSS: `<link rel="stylesheet" href="styles.css">`
  - [x] JS: `<script type="module" src="src/app.js"></script>`
- [x] File `.gitignore` sudah dibuat
- [x] File `README.md` sudah lengkap
- [x] File `CARA-UPLOAD-GITHUB.md` sudah ada (panduan upload)

## 🚀 Proses Upload

### Step 1: Buat Repository
- [ ] Login ke GitHub (https://github.com)
- [ ] Klik "New repository"
- [ ] Nama: `fsa-ecommerce-simulator`
- [ ] Set ke **Public**
- [ ] Klik "Create repository"

### Step 2: Upload Files
- [ ] Klik "uploading an existing file"
- [ ] Upload semua file:
  - [ ] `index.html`
  - [ ] `styles.css`
  - [ ] Folder `src/`
  - [ ] Folder `public/`
  - [ ] `README.md`
  - [ ] `LAPORAN-TUGAS-UAS.md`
  - [ ] `.gitignore`
- [ ] Commit message: "Initial commit - FSA E-commerce Simulator"
- [ ] Klik "Commit changes"

### Step 3: Aktifkan GitHub Pages
- [ ] Buka tab "Settings"
- [ ] Klik "Pages" di sidebar
- [ ] Source: Branch = **main**, Folder = **/ (root)**
- [ ] Klik "Save"
- [ ] Tunggu 2-5 menit
- [ ] Refresh halaman
- [ ] Copy link yang muncul

### Step 4: Test Website
- [ ] Buka link GitHub Pages
- [ ] Test semua fitur:
  - [ ] Buat pesanan baru
  - [ ] Lihat diagram FSA
  - [ ] Test mode simulasi
  - [ ] Test mode pengujian
  - [ ] Cek responsive (mobile view)

### Step 5: Update README
- [ ] Edit `README.md` di GitHub
- [ ] Ganti `[username]` dengan username GitHub lo
- [ ] Commit changes
